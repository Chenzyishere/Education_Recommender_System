# 第三章、第四章与实验结论（合并稿）

## 第三章 基于知识图谱的学习资源推荐

### 3.1 引言
在线教育推荐不仅要“预测对错”，还要“推荐路径合理”。仅依赖行为序列的模型在预测分数上通常较强，但容易出现知识跳跃。为此，本文在 SAKT 的基础上引入知识图谱约束，构建 KG-SAKT，用于同时优化预测性能与教学逻辑一致性。

### 3.2 推荐模型分析
本文对四类模型进行对比：`Pure-CF`、`DKT`、`SAKT`、`KG-SAKT`。

1. `Pure-CF`：只建模用户-知识点静态关系，缺乏时序信息。
2. `DKT`：时序拟合能力强，但对先修结构缺少显式约束。
3. `SAKT`：用注意力建模长程依赖，但默认不包含知识图谱关系。
4. `KG-SAKT`：在 SAKT 上叠加图扩散与逻辑约束，提升推荐可解释性。

### 3.3 推荐模型设计
KG-SAKT 的核心流程如下：

1. 序列编码：将“知识点+作答结果”映射到交互向量。
2. 注意力建模：通过因果注意力提取学习状态。
3. 图谱增强：对知识图谱做一跳/二跳扩散，获得结构先验。
4. 门控融合：动态融合序列特征与图特征。
5. 训练内逻辑约束：对“前置知识掌握应不低于目标知识”施加 margin 惩罚。
6. 推荐决策：输出全知识点掌握分布，结合先修关系筛选推荐项。

## 第四章 实验设计与分析

### 4.1 数据与预处理
数据来自 `data/skill_builder_data.csv`，清洗后得到 `data/assist9_cleaned.csv`。清洗流程包括：字段筛选、去重、按 `user_id + order_id` 排序、构建 `sequence_idx`、技能 ID 连续化映射。

### 4.2 知识图谱构建
针对教育数据“先修逻辑强、关系密度高、维护成本敏感”的特征，本文采用轻量级语义建模方案构建知识图谱。其目标是：在保证教学逻辑可表达的前提下，降低图谱构建与更新复杂度。

首先，定义知识图谱为有向图 \(G=(V,E)\)。其中，\(V\) 表示知识点集合（Knowledge Point, KP），\(E\) 表示先修依赖边集合。本文仅保留核心关系 `requires`，即“学习目标知识点前，需先掌握前置知识点”。

在存储层，采用三元组集合进行标准化表达：
\[
\mathcal{T}=\{(KP_{source},\ \mathrm{requires},\ KP_{target})\}
\]
其中，`KP_source` 为目标知识点，`KP_target` 为其先修知识点。该定义与推荐阶段的逻辑约束一致：若推荐 `KP_source`，则应优先检查 `KP_target` 的掌握状态。

系统初始化时，将三元组加载为内存语义结构：
`Graph = {kp:[prerequisites]}`  
例如：`{"矩阵乘法":["矩阵定义","向量运算"]}`。  
该结构直接用于推荐解释与路径合法性校验，可视为推荐过程中的“教学交通规则”。

本研究的构建流程如下：

1. 实体抽取：从课程大纲、教材目录与题目标签中抽取候选 KP。
2. 关系判定：依据教学顺序与学科核心链路，识别 `requires` 关系。
3. 三元组落盘：输出 `kg_triples.json/csv` 作为主存储。
4. 语义映射：构建 `Graph = {kp:[prerequisites]}` 供推理与解释使用。
5. 训练兼容：将三元组回写为 ID 邻接表，供模型训练阶段快速索引。

对应工程产物如下：

1. `data/kg_triples.json`、`data/kg_triples.csv`：三元组主存储文件。
2. `data/kg_graph_semantic.json`：语义字典（`Graph = {kp:[prerequisites]}`）。
3. `data/kg_adj_list.json`：由三元组映射得到的 ID 邻接表（训练兼容层）。

### 4.3 指标体系
实验同时报告预测指标与逻辑指标：

1. 预测指标：`AUC`、`RMSE`。
2. 逻辑指标：`Path`、`PVR`、`APC`、`VS`、`RDC`。

### 4.4 实验结果（基于最新 `logic_metrics_comparison.csv`）

| 模型 | AUC | RMSE | Path(%) | PVR(%) | APC(%) | VS | RDC(%) |
|---|---:|---:|---:|---:|---:|---:|---:|
| Pure-CF | 0.5039 | 0.6520 | - | - | - | - | - |
| DKT | 0.8377 | 0.3933 | 42.01 | 20.43 | 79.93 | 0.3715 | 5.20 |
| SAKT | 0.7981 | 0.4186 | - | - | - | - | - |
| KG-SAKT | 0.8142 | 0.4113 | 59.23 | 16.99 | 83.87 | 0.3240 | 35.94 |

### 4.5 结果讨论

1. 预测性能上，`DKT` 的 AUC 最高；`KG-SAKT` 明显优于 `SAKT`。
2. 逻辑一致性上，`KG-SAKT` 在 `Path / PVR / APC / VS / RDC` 上整体优于 `DKT`，说明图谱约束对推荐路径质量有提升。
3. 综合来看，`KG-SAKT` 在“预测+逻辑”双目标下更均衡，符合教育推荐场景需求。

## 实验结论与写作建议

### 1. 结论
将知识图谱引入 SAKT 后，可以在保持较好预测能力的同时，显著提升推荐路径的逻辑性与可解释性，尤其体现在 `Path` 与 `RDC` 等教育导向指标上。

### 2. 局限
当前图谱仍属于轻量级规则与语义混合构建，与真实课程先修图仍有差距；后续可引入专家标注图谱或数据驱动图谱进一步增强。

### 3. 后续工作

1. 融入更真实的课程先修关系（人工+自动混合构图）。
2. 做多随机种子统计（均值±标准差）增强结论稳健性。
3. 增加线上推荐指标（覆盖率、多样性、路径长度控制）支撑应用落地。
